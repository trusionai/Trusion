## What these results do and do NOT show
- Tests run **in one Node process on SQLite** with a **local mock** for AI providers and synthetic APK fixtures built by this repo's own encoder. They do not exercise Postgres/Supabase, any real AI provider, a real payment gateway, a real APK corpus, a browser, or multiple instances.
- Mutation check performed manually on the SSRF guard: removing the 169.254.0.0/16 range failed 5 tests; skipping per-hop DNS validation failed 2 tests (both restored; suite green).
- "DNS rebinding" is covered by (a) re-resolving and re-validating every hop and (b) a real-socket test proving the transport connects to the *pinned* IP regardless of what the hostname would resolve to. A hostile live DNS server was not used.
- Type-check uses a shim, so it validates this repo's own types only, not correct use of Node APIs.
- No E2E/browser/cross-platform/PWA/accessibility tests exist yet (spec §15–17): **not done**.
